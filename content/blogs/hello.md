## Welcome to the Publishing Site

This publishing engine hosts technical writeups, systems case studies, homelab blueprints, and practical thoughts on modern software tooling.

### Why Markdown?

Writing in pure Markdown provides three foundational advantages:

1. **Portability**: Content lives in text files under Git version control without database locks.
2. **Durability**: No proprietary CMS migrations or schema deprecations.
3. **Speed**: Zero runtime overhead when compiled to static HTML at the edge.
